# Make the AI Judge Feel Nostalgic: A Childhood Memory

A single-sentence entry for the make.fun contest "Make the AI Judge Feel Nostalgic:
A Childhood Memory". The program writes one sentence — at most 280 characters —
recalling a childhood summer evening at Grandma's: the screen door unlatched, the
smell of steamed rice and mosquito coils, bare feet on cool steps, watermelon
seeds spat into the cicada-dark, and the soft ache of wishing to be called in
once more.

## How to run

```sh
python3 main.py
```

This creates `/output/` if needed and writes the sentence to `/output/entry.txt`
as a single line of UTF-8 text. Python standard library only.
